# Introduction
This project explores the data science job market using SQL, with a primary focus on Data Analyst roles. The goal is to identify the highest-paying job opportunities, understand the most in-demand skills, and discover which skills offer the best combination of high demand and high salary.

Through SQL queries, I explored job postings, salary distributions, and skill requirements to uncover insights that can help aspiring Data Analysts understand what employers are looking for and which skills are worth prioritizing.

Check SQL Queries here: [project_sql folder](/project_sql/)

# Background
The data analytics field continues to evolve, and understanding the job market is essential for anyone planning to pursue a career as a Data Analyst.

However, knowing which technical skills to learn can be challenging. Some skills may appear frequently in job postings, while others may be associated with higher-paying opportunities.

To better understand these differences, I used a 2023 job postings dataset to investigate the following questions:
1. What are the top-paying Data Analyst jobs?
2. What skills are required for these top-paying jobs?
3. What skills are most in demand for Data Analysts?
4. Which skills are associated with higher salaries?
5. What are the most optimal skills to learn?


# Tools I Used
Several tools were used throughout this project to query, manage, and analyze the job postings dataset:

    SQL: Used as the primary tool for querying the database, performing data analysis, and extracting meaningful insights from the dataset.

    PostgreSQL: Used as the relational database management system to store and manage the job posting data.

    Visual Studio Code: Used as my development environment for writing, organizing, and executing SQL queries.

    Git & GitHub: Used for version control, managing project files, and sharing SQL scripts and analysis.
